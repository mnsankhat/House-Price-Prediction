# 🏠 House Price Prediction System

A Machine Learning-based web application that predicts house prices based on various property features.

---

## 🚀 Features

- Predict house prices in real-time
- User-friendly interface using Streamlit
- Handles multiple input features (BHK, area, furnishing, etc.)
- Accurate predictions using trained ML model

---

## 🧠 Machine Learning Concepts Used

- Regression Model (Random Forest)
- Data Preprocessing
- Feature Encoding (One-Hot Encoding)
- Model Training & Prediction

---

## 🛠️ Tech Stack

- **Language:** Python
- **Libraries:** Scikit-learn, Pandas, NumPy
- **Frontend:** Streamlit
- **Tools:** Jupyter Notebook, Git, GitHub
